# Just Another TD

Tower defence on **Godot 4.3+** where towers evolve through combat **feats**.

See [DESIGN.md](DESIGN.md) for the core fantasy and systems.

## Run

1. Install [Godot 4.3+](https://godotengine.org/download)
2. Import this folder as a project
3. Press F5

### Controls (prototype)

| Input | Action |
|-------|--------|
| LMB on map | Place archer tower (costs gold) |
| LMB on tower | Select / open feat panel |
| Space | Start next wave |
| Esc | Deselect / cancel |
